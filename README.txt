HOW TO FINISH AND PUBLISH YOUR PORTFOLIO
=========================================

WHAT'S ALREADY DONE
- index.html is fully written: 7 project cards with real titles,
  descriptions, and metrics
- 6 of 7 screenshots are in the images folder, pulled from your files

WHAT'S LEFT

1. EXCEL SCREENSHOT
   Open Global_Superstore_Dashboard_.xlsx, screenshot the Dashboard tab,
   and save it as:  images/excel-dashboard.png
   (Until then that card shows a note saying the file is missing.)

2. LINKS
   Each card has a button with href="#". Replace "#" with a link to the
   actual file — GitHub links for the .sql and .ipynb, Drive share links
   for the PDFs/PPTX/XLSX (sharing set to "anyone with the link").
   The .pbix can link to the Drive file too, or to a published
   Power BI web report if you have one.

3. PUBLISH ON GITHUB PAGES (free)
   a. github.com → create a repository, e.g. "portfolio"
   b. Upload index.html + the images folder (drag-and-drop works)
   c. Repo Settings → Pages → Source: main branch → Save
   d. Your site goes live at https://yourusername.github.io/portfolio/

TIP: put the project files themselves in the same repo (a /files folder)
and link to them relatively, e.g. href="files/SQL_Code.sql" — then
everything lives in one place and no Drive permissions to worry about.
